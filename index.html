Gastroscopía (Endoscopía Digestiva Alta)

¿Por qué realizar este estudio?

Sirve para diagnosticar y tratar enfermedades del esófago, estómago y duodeno. Permite tomar biopsias sin dolor y aplicar tratamientos como detener hemorragias, tratar várices o extraer cuerpos extraños.

¿En qué consiste?

Se introduce un tubo flexible con cámara por la boca para explorar el tracto digestivo superior.

¿Necesita preparación?

Solo requiere ayuno.

¿Lleva anestesia?

No es doloroso. Puede realizarse con anestesia local en la garganta o sedación intravenosa.

×

Colonoscopía

¿Por qué realizar este estudio?

Es el método más efectivo para detectar pólipos y prevenir el cáncer colorrectal. Permite observar todo el colon, tomar biopsias y realizar tratamientos como la extracción de pólipos.

¿En qué consiste?

Se introduce un tubo flexible por el ano para explorar el intestino grueso. El estudio dura aproximadamente 20 minutos.

¿Necesita preparación?

Sí, requiere una limpieza previa del intestino.

¿Lleva anestesia?

Se realiza con sedación y es necesario asistir con acompañante.

×

Extracción de Pólipos

¿Por qué realizar este estudio?

Permite resecar pólipos y prevenir o detectar precozmente lesiones de riesgo.

¿En qué consiste?

Se utiliza instrumental endoscópico especializado para extraer la lesión de forma segura.

¿Necesita preparación?

Sí, dependiendo de la vía del procedimiento.

¿Lleva anestesia?

Se realiza con sedación.

×

Test de Aire Espirado

¿Por qué realizar este estudio?

Ayuda a detectar sobrecrecimiento bacteriano (SIBO) e intolerancias digestivas.

¿En qué consiste?

Se analiza el aire espirado en diferentes intervalos luego de ingerir una solución específica.

¿Necesita preparación?

Sí, requiere una preparación previa específica.

¿Lleva anestesia?

No. Es un estudio simple, no invasivo e indoloro.
